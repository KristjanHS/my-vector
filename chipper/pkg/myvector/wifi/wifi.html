WiFi networks

Saved on Vector

    Save one network per floor. Vector stays on a network while it works (at boot it rejoins the last one), so wire-pod checks every 3 minutes and switches Vector to a saved network at least 8 dB stronger. Test joins a network, checks Vector keeps its address and reaches wire-pod, then goes back; Switch does the same and stays. Either goes back if a check fails. Vector is offline for ~10–40 s meanwhile.

    Add a network

    2.4 GHz WPA/WPA2 networks only. Vector stays online; a saved network counts from its next boot. The password is stored on Vector only: wire-pod keeps no copy and this page never shows it again. It crosses your home network to wire-pod unencrypted (wire-pod's web UI is plain HTTP).
