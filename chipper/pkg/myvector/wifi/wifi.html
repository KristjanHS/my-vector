WiFi networks

Saved on Vector

    At boot Vector joins the strongest saved network in range — save one per floor. It stays on a network while that one works; it switches when the connection drops or at the next boot.

    Add a network

    2.4 GHz WPA/WPA2 networks only. Saving restarts Vector's WiFi (~10 s offline). The password is stored on Vector only: wire-pod keeps no copy and this page never shows it again. It crosses your home network to wire-pod unencrypted (wire-pod's web UI is plain HTTP).
